# Python Practice & Coursework

Welcome to the **Python Practice & Coursework** repository! This repository contains a structured collection of daily practice scripts, projects, and assignments tracking my journey in learning core Python programming concepts from fundamentals to advanced topics step-by-step.

---

## 📁 Repository Structure

```
python-practice-coursework/
├── 📁 python-basics/      # Core language concepts, daily exercises, OOP & standard libraries
├── 📁 assignments/        # Coursework assignments & logic puzzles
└── 📁 mini-projects/     # Interactive CLI games & database-backed projects
```

## 💻 How to Run

Clone the repository and run any script using Python 3:

```bash
git clone https://github.com/JishnuMadhu/python-practice-coursework.git
cd python-practice-coursework

# Run Python Basics scripts
python python-basics/day_10.py

# Run Mini Projects
python mini-projects/hangmangame.py
```
